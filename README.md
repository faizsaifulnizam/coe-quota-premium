# coe-quota-premium

[![CI](https://github.com/faizsaifulnizam/coe-quota-premium/actions/workflows/ci.yml/badge.svg)](https://github.com/faizsaifulnizam/coe-quota-premium/actions/workflows/ci.yml) [![license: MIT](https://img.shields.io/badge/license-MIT-2E7D6B.svg)](LICENSE) ![Python 3.12](https://img.shields.io/badge/Python-3.12-C0552B.svg) ![DuckDB](https://img.shields.io/badge/analytics-DuckDB-22607B.svg) [![data: data.gov.sg](https://img.shields.io/badge/data-data.gov.sg-14293D.svg)](https://data.gov.sg/datasets/d_69b3380ad7e51aff3a7dcc84eba52b8a/view)

> **Answer:** Since May 2022, Cat A/B premium changes have a stronger descriptive association with changes in bids per quota than with quota changes. Cat C/D show the opposite ordering. Yet Cat A’s September 2026 record occurred while quota was recovering. Bid counts help describe auction pressure, but this dataset cannot explain bidders’ values or establish causes.

**Status:** built 2026-10-04; second external-review repairs documented in [review dispositions](docs/review-remediation.md). Results below describe the **2026-10-04 pull**, through September 2026. Part of a six-repo series on Singapore’s public data.

## Key numbers (all reproducible)

- **Association, May 2022 onward:** premium changes vs bids-per-quota changes: Spearman ρ **+0.37 / +0.55** for A/B; vs quota changes: **−0.14 / −0.09**. For C/D, quota has the larger absolute association: **−0.17 / −0.28**, versus bids-per-quota **+0.04 / −0.06**. Earlier, definition-consistent A/B samples have **190 changes each**: quota **−0.049 / −0.078**, bids-per-quota **+0.552 / +0.483** ([attribution CSV](outputs/coe_attribution.csv)).
- **Jump events — top 5 S$ increases per category:** 25 events, **not** the series’ 25 largest increases; smallest selected increase **S$1,050**. Quota moved down 13 / up 11 / flat 1, median **−0.1%**; bids-per-quota rose in **17/25**, median change **+0.25**. **Two** selected jumps followed quota cuts above 40%: C, **2023-02 R1, +S$8,010 after −43.6%**; D, **2020-08 R1, +S$1,191 after −42.1%** ([jump CSV](outputs/coe_jumps.csv)). These are co-occurring changes, not causal supply estimates.
- **A record on a recovering quota:** A reached **S$133,009** in 2026-09 R1 (quota **1,195**); R2 was **S$131,890** (quota **1,193**). For **January–September in both years**, A’s average quota rose **962 → 1,252 (+30%)**, 2024 → 2026; average premium rose **S$88,078 → S$119,812**. B’s September premiums, **S$135,001 / S$133,000**, remained below its **S$150,001** record in **2023-10 R2**, quota 472 ([pressure CSV](outputs/coe_pressure.csv)).
- **Structural checks, not a source-accuracy certificate:** **1,980/1,980 raw rows retained**, 0 staging exclusions, **10/10 staging checks**. Two cells disagree with LTA’s historical table; source values remain untouched and sensitivity excludes changes touching them ([audit](docs/data_audit.md)).

## The question

An auction brings a quota of certificates together with submitted bids. When premiums jump, did quota fall, or did bid counts rise relative to quota? This repo compares those movements **exercise by exercise**, not through monthly averages.

A/B category composition changed before May 2022 as well. Taxis left A in August 2012; the 97 kW criterion began in February 2014 ([LTA historical tables](https://www.lta.gov.sg/content/dam/ltagov/who_we_are/statistics_and_publications/statistics/pdf/COE_Result_2010_2014.pdf)). Earlier A/B association estimates therefore use **February 2014 R2–April 2022**; post estimates start in **May 2022 R2**. Both endpoints of each change lie within the same definition. Earlier observations remain visible as context.

## The data

- **LTA COE Bidding Results / Prices**, via [data.gov.sg](https://data.gov.sg/datasets/d_69b3380ad7e51aff3a7dcc84eba52b8a/view): **1,980 rows = 396 exercises × 5 categories**, 2010-01 → 2026-09. Both rounds are in one CSV. No category is missing; no exercises Apr–Jun 2020.
- Fields: month · round · category · quota offered · bids received · successful bids · premium.
- **Premium is the final quota premium in S$, paid by every successful bidder in that category.** It is the auction clearing price, not the lowest winning reserve price or the PQP (the renewal price). LTA describes the clearing threshold as the highest unsuccessful bid plus S$1; its worked example has winning reserve prices S$100 and S$88 but a premium of S$71 ([rules and example](https://onemotoring.lta.gov.sg/content/onemotoring/home/buying/upfront-vehicle-costs/certificate-of-entitlement--coe-.html)).
- Categories under current rules: A — non-electric cars ≤1,600 cc and ≤97 kW, or fully electric cars ≤110 kW; B — cars above the relevant limits; C — goods vehicles and buses; D — motorcycles; E — open, except motorcycles. These are **not** the definitions for every historical row.
- Raw CSV is immutable and gitignored. The [downloader](src/download.py) validates structure and checks cached bytes against the SHA-256 manifest. Data: Singapore Open Data Licence, © Land Transport Authority.

## Method

DuckDB SQL is first-class; Python validates, correlates and draws.

1. **Pull:** [download.py](src/download.py) → raw CSV plus SHA-256/coverage manifest. Both files stage before publication.
2. **Audit:** [data_audit.md](docs/data_audit.md) records grain, units, dirty-cell counts, definition changes and source conflicts.
3. **Stage:** [01_staging.sql](sql/01_staging.sql) parses comma-formatted integers and creates one row per exercise/category. All 10 [checks](sql/05_checks.sql) run before replacing the parquet. Only the latest month may legitimately contain R1 alone; older incomplete months still fail.
4. **Measure:** [02_metrics.sql](sql/02_metrics.sql) computes lags in month/round order within category, with pause and May-2022 flags.
5. **Select events:** top 5 **positive S$ changes per category**, excluding the 2020 resume and disputed D spike. Full history remains in `coe_pressure.csv`.
6. **Compare changes:** [analysis.py](src/analysis.py) computes per-category/per-period Spearman correlations using **average ranks for ties**. Premium and quota use **% changes**; bids-per-quota uses its **level change**, not a percent. The A/B scope excludes earlier definitions and cross-definition changes.
7. **Check sensitivity:** 5 A/B variants (base, resume included, absolute-change basis, Pearson, bid-count % growth), an all-category source-conflict exclusion, and a rank-residual partial ([sensitivity](docs/sensitivity.md)).
8. **Draw:** [figures.py](src/figures.py) creates six PNGs and six site mirrors. Each producer stages its complete batch before replacing targets; [publish.py](src/publish.py) rolls back ordinary promotion failures.

### The comparison, made computable

```text
bids per quota = bids received ÷ quota           bids submitted per certificate
quota change   = quota vs previous exercise     certificates offered
```

**Bids-per-quota is not a count of unique participants.** Companies can submit multiple bids. Quota is announced before bidding; bid growth does not mechanically raise it. Because quota is also the ratio’s denominator, the partial correlation conditions on bid-count growth, but does **not** identify a causal supply effect.

Spearman describes co-movement without letting extreme observations set the linear fit. Pearson and absolute-change variants are shown, not hidden. A weak change–change correlation does not mean supply never matters. Level histories, selected jumps and all-exercise correlations answer different questions.

### The association in words

For A/B after May 2022, bids-per-quota changes have the stronger descriptive association (**+0.37 / +0.55** vs quota **−0.14 / −0.09**). C/D have the opposite ordering under the base Spearman specification, not an established supply mechanism.

The largest selected increase is B **+S$26,990**, quota **633 → 657 (+3.8%)**, bids-per-quota **1.34 → 1.99**. A’s largest is **+S$16,579**, quota **924 → 923 (−0.1%)**, bids-per-quota **1.28 → 2.04**. Both are **2024-01 R2**. Conversely, C and D each have a selected increase alongside a quota cut above 40%. Selection does not prove causes.

Counts cannot reveal the reserve-price distribution. A record premium alongside recovering quota is compatible with several explanations; the file cannot choose among them.

### Rules chosen, and why

| Rule | Choice | Why |
|---|---|---|
| Unit | month + bidding round, within category | one auction exercise, no monthly averaging |
| A/B scope | Feb 2014 R2–Apr 2022; May 2022 R2 onward | no deltas crossing category definitions |
| Historical context | full source retained in plots and pressure CSV | not treated as one comparable population |
| 2020 pause | exclude resume delta; re-include in sensitivity | four-month gap is not an ordinary adjacent-exercise change |
| Jump basis | top 5 positive S$ changes per category | quoted price unit; explicit groupwise selection |
| Source conflicts | preserve raw; flag and test exclusions | official data can contain errors |
| C/D/E split | May 2022 period split only | not evidence of an unchanged auction mechanism over all history |

### Validation — receipts, not claims

- **10/10 structural checks**, 1,980 raw rows retained, zero staging exclusions. Structure is not source truth.
- **Raw-cell recompute:** 2013-01 R1 A premium 92,100; 2022-05 R2 B 95,889; 2026-09 R2 E 137,000; 2026-09 R2 A premium change −1,119. Stdlib recomputation agrees with staging.
- **Counted statistics exclusions:** **1,975 − 5 pause − 2 May boundary − 196 earlier-definition A/B = 1,772** base changes. Source-conflict sensitivity removes 2 further D changes (**1,770**); disputed B changes were already out of scope.
- **Sensitivity:** A/B signs and ordering remain stable. Absolute-change vs percentage Spearman values differ by less than 0.03; the bid-count variant changes the pressure metric, not just its scale. Resume inclusion moves A/B correlations by less than **0.017**. Post-2022 partial quota correlations are **−0.20 / −0.22**, descriptive only. A/B Pearson quota magnitude remains below 0.28.
- **Rounding:** correlation CSVs retain full precision; prose rounds directly to 2–3 decimals. Other CSV fields display 2–4 decimals; sums of rounded cells may differ in the last digit.
- **Publication scope:** CSVs, figures/site mirrors and raw/manifest each publish as their own batch with exception rollback. This is **not** a transaction across all pipeline commands, simultaneous atomic visibility to readers, or protection against power loss. Run the full pipeline successfully before committing regenerated artifacts.

### Limits

**Not a forecast, not causal, not bid values.** The file does not identify bidders, reserve values, dealer behaviour or motives. C/D/E period comparisons can also reflect other rule changes, including motorcycle deposit/TCOE changes. No inference here isolates those effects.

Two source conflicts remain visible: **2010-02 R1 B quota 1,154 vs LTA table 693**; **2010-01 R2 D premium S$20,090 vs table S$852**. The apparent B undersubscription is not treated as established auction behaviour. The sensitivity excludes both disputed observations’ changes and their following changes; the source itself is not repaired.

## Reproduce

### Linux/macOS (Bash)

```bash
git clone https://github.com/faizsaifulnizam/coe-quota-premium && cd coe-quota-premium
uv venv .venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt

python src/download.py
python src/build_dataset.py
python src/analysis.py
python src/figures.py
python tests/smoke_test.py
python -m unittest discover -s tests -p "test_*.py"
```

### Windows (PowerShell, no activation needed)

```powershell
git clone https://github.com/faizsaifulnizam/coe-quota-premium
cd coe-quota-premium
$env:PYTHONUTF8 = "1"
uv venv .venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -r requirements.txt

.venv\Scripts\python.exe src/download.py
.venv\Scripts\python.exe src/build_dataset.py
.venv\Scripts\python.exe src/analysis.py
.venv\Scripts\python.exe src/figures.py
.venv\Scripts\python.exe tests/smoke_test.py
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
```

`python -m venv .venv` and that environment’s `python -m pip install -r requirements.txt` are alternatives to uv. Use Python 3.12.

Check the dated A rows in `outputs/coe_pressure.csv` and B’s January 2024 jump above. A later `src/download.py --force` can add exercises or restate source values; rerun all stages and review the prose/banner/site against regenerated outputs. January–September 2024/2026 comparison receipts stay fixed to those months rather than silently including later releases. Correlations and event rankings may change on refresh.

## Out of scope

Premium forecasts; causal bidder attribution; dealer-level or bid-value models; PQP renewal series; cross-country comparisons.
